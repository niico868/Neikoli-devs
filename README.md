# neikoli.com

Portfolio, client-intake hub and private dashboard for Nico (Nexus Forge).

See [docs/PLAN.md](docs/PLAN.md) for the stack, file structure, phases and test checklist.

```
npm install
npm run dev
```

Hero tuning (gravity, bounce, timings, colours, copy, reveal cards): `src/scripts/hero/config.ts`.
